# 🚀 CodeAcademy - Interactive Coding & Learning Platform

**CodeAcademy** is a lightweight, fully responsive, and **100% FREE** open-source interactive learning platform designed for aspiring software developers. Learn programming languages, write code directly in your browser, simulate electronics with Arduino, and track your daily coding streak—all in one place!

---

## ✨ Features & Highlights

- 💯 **100% Free & Open Source:** No hidden subscriptions, no daily lesson limits, and no paywalls. Enjoy unlimited learning!
- 💻 **Multi-Language Support:** Practice 13+ programming languages and technologies, including:
  - **Python, Java, JavaScript, PHP, C, C++, C#, Ruby, Assembly (ASM)**
  - **HTML & CSS** (with live web previews)
  - **Arduino** (with code compilation simulator)
  - **Linux Terminal** (command-line practice)
- 📱 **Mobile First & Fully Responsive:** Seamless UI with dedicated mobile tab navigation (**Lesson**, **Code**, **Output**) for an optimal experience on smartphones and tablets.
- 📱 **Device Session Management:** Save your login session automatically across multiple registered devices.
- 🔥 **Daily Streak System:** Track your continuous coding habits and build daily learning discipline.
- 📁 **File & Code Workspace:** Create, open, and manage custom code files right in your browser.
- 🎨 **Modern Dark UI & Animations:** Beautiful dark-themed interface with smooth side-drawer navigation and interactive panels.

---

## 🛠️ Built With

- **HTML5** & **CSS3** (Custom CSS Variables & Flexbox/Grid)
- **Vanilla JavaScript (ES6+)**
- **FontAwesome Icons**
- **HTML5 LocalStorage API** for state and session persistence
